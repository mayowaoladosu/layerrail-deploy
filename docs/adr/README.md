# Architecture Decision Records

Architecture Decision Records capture decisions that materially affect product behavior, security, tenancy, reliability or operations.

Each record includes its status, date, relevant requirements, context, decision and consequences. Accepted records are immutable; superseding decisions receive a new record that links to the old one.
